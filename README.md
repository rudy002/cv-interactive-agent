# 🤖 CV Interactive Agent

An AI-powered interactive CV — ask questions about my profile and get instant, context-aware answers.

🔗 **Live demo:** [cv-interactive-agent.vercel.app](https://cv-interactive-agent.vercel.app)

## What it does

Instead of reading a static PDF, visitors can chat directly with an AI agent that knows everything about my background, skills, and experience. The agent responds in natural language, making the experience dynamic and conversational.

## Tech Stack

- **Next.js 14** (App Router) — frontend & API routes
- **TypeScript** — full type safety
- **n8n** — AI agent workflow orchestration (via webhook)
- **Tailwind CSS** — styling
- **Vercel** — deployment
